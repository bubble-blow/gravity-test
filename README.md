# GravityDemo 轨道类型数学估算

下面根据 `GravityView.initializeBodies()` 中的初始参数，估算该 3 体系统是否会发散（逃逸）。

## 1. 初始条件（来自代码）

- 引力常数：`G = 9000`
- 质量：`m1 = m2 = 1800`, `m3 = 160`
- 位置：
  - 大天体：`(-d, 0)` 与 `(d, 0)`
  - 小天体：`(0, -0.7d)`
  - 其中 `d = 0.22 * min(width, height)`
- 初速度：
  - 两个大天体：`v1 = (0, +v)`, `v2 = (0, -v)`
  - `v = 0.5 * sqrt(G*m2/(2d+1))`（初始速度已减半）
  - 小天体由动量补偿得到，随后再做系统总动量归零（因此质心系中总动量为 0）。

## 2. 用总机械能判断是否“整体发散”

在忽略手势输入、忽略数值误差时，可用总能量符号判断系统是否整体无界：

- 若 `E_total < 0`，系统整体倾向于有界（不整体发散）。
- 若 `E_total > 0`，存在整体无界/逃逸的可能。

### 2.1 两个大天体子系统

两大天体间距约 `r12 = 2d`，代码给的速度近似双星圆轨道速度，因此：

- 动能：`K12 = m * v^2`（两个同质量天体）
- 势能：`U12 ≈ -G*m^2/r12`

由于当前 `v` 被减半，故 `v^2` 变为原来的 `1/4`，即 `K12` 约为圆轨道所需值的 `1/4`；而 `U12` 不变，
因此大天体子系统总能量更偏负，体系更不容易整体发散。

### 2.2 小天体贡献

小天体初速接近 0（在此构型下动量补偿后仍很小），与每个大天体距离：

`r13 = r23 = sqrt(d^2 + (0.7d)^2) = d*sqrt(1.49) ≈ 1.2207d`

故小天体势能近似为：

`U3 ≈ -G*m3*m1/r13 - G*m3*m2/r23 = -2*G*m3*m/(1.2207d)`

这是显著负值，且小天体动能初始较小，因此把系统总能量明显拉到负值。

## 3. 结论

- 在当前初始化参数下，系统初始总机械能通常为**负值**，可判为**整体有界**，即“默认不发散”。
- 但这是 3 体系统：轨道一般是复杂的准周期/混沌形态，局部上可能出现小天体被甩得更远，
  尤其在用户滑动手势持续注入能量后，可能从有界转为逃逸。

## 4. 一个数量级例子（以 `min(width,height)=1080` 为例）

- `d = 0.22*1080 = 237.6`
- 大天体轨道速度 `v ≈ 0.5*sqrt(9000*1800/(2*237.6+1)) ≈ 92 px/s`
- 两大天体子系统 `K12 + U12` 为明显负值（相较圆轨道速度降为 1/2）
- 小天体与两大天体的总势能约为 `-1.8e7` 量级（像素单位下）

因此初始 `E_total < 0`，结论仍是：**初始态不发散**。
